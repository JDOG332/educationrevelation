## 5. Summary, recommendations and suggested paper text

### Findings

1. Spectrum lemma: same-spectrum pairs give exact Psi equal to 7e-16. At finite N, no pair differs in Psi (0 of 12 pairs at p < 0.01 at every N; largest abs t 2.52 against about 2.23 expected under the null). The largest difference falls as N^-0.56, like the SE (N^-0.50). The one channel that sees more than the spectrum, the likelihood weights, does differ between same-spectrum states (w_LI differs at p < 0.01 in up to 10 of 12 pairs), but only by at most 9.8e-03 at N = 1e4, and it never changed n_active, n_unique or C_eff (max abs difference of C_eff 4.2e-05).
2. Floor law: for I/4, R12 = a N^-b with a = 34.50 +/- 1.56, b = 1.0033 +/- 0.0042 (chi^2 7.1 / 8); with b = 1, a = 33.33 +/- 0.31. First-order theory: N E[I_hat] = (sum_k p_k Tr D_k^2 - Tr rho^2)/ln 2 = 24.75/ln 2 = 35.71 (measured mean N I_hat 35.01), and N E[sqrt(I_hat1 I_hat2)] = 34.30. This 100-seed fit is a low draw: the 3000-seed rerun (Phase 3, 3000 seeds per N, fit over N >= 1e4) gives a = 34.27 +/- 0.08 (b = 1) against the prediction 34.32 +/- 0.01. LI/MLE and MLE/MLE pairings are identical here, because for I/4 the LI estimate was always positive, and then LI equals the MLE.
3. P3: the asymmetry is first order (linear) only for inputs with Bloch components both along and across the measured axes (tilted input: exponent k = 0.98). For |+>|0> and for cos(pi/8)|00>+sin(pi/8)|11> it is second order (k = 1.98), although a straight line still gives R^2 = 0.981. For Bell input it is exactly zero. At the paper's gamma = 0.5 the tilted input needs 9.7e+09 counts for a 5 sigma slope; with projective measurements (gamma = 1) it needs 2.4e+05 (2 runs per order per theta at N = 1e+04). Over the full theta range the tilted-input asymmetry peaks near theta = 0.4 and falls (k = 0.56, R^2 = 0.45), so the small-commutator restriction is needed. The run counts assume the single-run SD falls as N^-1/2; this holds for the tilted input (measured/predicted 0.92 to 1.03 at N = 1e5 and 1e6) but the SD falls more slowly for the Bell and partially entangled inputs (ratio up to 1.85 at N = 1e6), whose counts at large N are therefore underestimated by up to a factor 3.4.
4. C_eff: with the paper's tau = 1 the convergence factor is a model count. C0 stays above 0.99999 in every run; models that agree are merged, so C_eff = 1/n_active exactly (1/2 with two models, 1/3 with three). The misspecified rank-1 model is dropped by eta for every mixed state (its held-out log-likelihood is 600 to 2700 nats worse), and merged with MLE for the Bell state, where it is correct. Adding a correct method lowers Psi (Werner 0.8: 0.275 with two, 0.184 with three), which is Lemma 2 working as designed but is not information about the state. With per-count weights (tau = N) more models stay active and C0 moves (down to 0.97), but the max(delta_i, delta_j) edge rule then lets the unstable rank-1 model (delta_R1 = 0.126 against 3.8e-4 for I/4) absorb the good models, and for the dephased Bell state it was counted as a separate witness in 2 of 20 runs.

### Recommendations (not applied in the code; each changes a definition)

1. Algorithm 1, step 1: define delta_i from two independent resamples (sampling spread). The literal text (one resample, two starting seeds) gives delta_LI = 0 and delta_MLE of about 1e-17, so the edge is decided by round-off: in Phase 1, n_unique = 1 in 19, 18, 2 and 17 of 20 runs for Werner 0.8, Werner 0.2, the dephased Bell state and I/4, and the delta_reg sweep moved Psi by 0.28 instead of 6e-5.
2. Algorithm 1, step 3: use delta_ij = min(delta_i, delta_j), not max, and a non-strict test JSD <= delta_ij. With max, one unstable model sets the tolerance for every pair (delta_R1 = 0.126, 330 times the others for I/4). With a strict test, exact duplicates (JSD = 0 = delta at infinite N) are not merged, so R jumps from 1/2 at every finite N to 1 at N = infinity.
3. Weights: with tau = 1 on summed log-likelihoods the softmax is one-hot at N = 1e4 (for the SIC-aligned Bell state the cross-validated gap LL(MLE) - LL(LI) has median 62 nats, range 34 to 114 over 200 runs (Phase 3), so w_LI is at most 2e-15). Either use per-count log-likelihoods (tau = N) together with recommendation 2, or state plainly that C_eff = n_unique/n_active in practice (= 1/n_active in every run here, since n_unique = 1 throughout) and treat it as a count of distinct estimator families, not as a measure of agreement.
4. V2 and the gate floor: replace F_gated ~ eps/(1+eps) by the floor law R12 = a/N with a = 34.3 +/- 0.1 (Phase 3, 3000 seeds per N, fit over N >= 1e4) for this POVM and pipeline (Section 2 above). Optionally bias-correct I_hat by subtracting (sum_k p_k Tr D_k^2 - Tr rho_hat^2)/(N ln 2) near I/4.
5. Regularization: state the deterministic offsets instead of a blanket 1e-5 bound. Near I/4, I(rho~) = (1 - delta)^2 I(rho_hat), a relative change of -2 delta (measured -2.008e-04 for I/4 at delta = 1e-4, SD over runs 1.3e-06). For a pure reconstruction, 1 - I(rho~) = S(rho~)/2 = 8.8e-6 at delta = 1e-6 and 6.3e-4 at delta = 1e-4. The 1e-5 claim holds only for delta_reg <= 1e-6.
6. P3: use the signed difference of means across runs, not the mean of per-run abs(Psi12 - Psi21), whose noise floor is about 1.13 x SD(Psi) (6.1e-3 at N = 1e4). Test linearity with the log-log exponent, not R^2 > 0.9. Calibrate with projective or near-projective measurements and an input with Bloch components along and across the axes. Keep the theta <= 0.2 restriction.
7. P2: replace the entanglement-sensitivity claim by the spectrum lemma; the separable control is then a check of the lemma, not a test of entanglement.

### Suggested paper text

*Spectrum lemma.* In the limit of many counts both reconstructions converge to the true state, so F tends to 1, the gate depends only on the eigenvalues, the two estimators agree and the redundancy decision does not depend on the state; Psi is then a function of the spectrum of rho and of the apparatus alone. In simulation, Werner states and separable states of the same spectrum give Psi values that agree to within the sampling noise at every N from 1e3 to 1e6, and the residual difference falls like that noise. Psi is therefore not a witness of entanglement; the likelihood weights do see more than the spectrum, but they changed C_eff by at most 4e-05 and never changed the redundancy partition.

*Floor law.* For a state with I(rho) = 0 reconstructed by linear inversion (or R rho R MLE) from N counts per batch of the 16-outcome product SIC-POVM, R12 = a N^-1 (1 + o(1)) with a = 34.3 +/- 0.1 (simulation, Phase 3, 3000 seeds per N, fit over N >= 1e4; first-order theory 34.32), so the ignorance floor eps/(1+eps) is reached only for N of order a/eps, about 3e9. A laboratory value of a outside roughly [31, 38] (10 percent, to allow for detector and calibration effects) falsifies the stated pipeline model. Psi at the floor is D_hat x C_eff x a/N, linear in D_hat.

*P3.* The order asymmetry of Psi is linear in the commutator norm only when the input has Bloch components along and across the measured axes; for other inputs it starts at second order, and for a maximally entangled input it vanishes identically. At measurement strength gamma = 0.5 a 5 sigma slope needs about 1e+10 detected counts; with projective measurements about 2e+05 suffice, using the signed difference of run means. For the input where the asymmetry is linear, the linear form holds for theta <= 0.2 and fails at larger angles, where the asymmetry passes through a maximum.

*Convergence factor.* With the paper's weight rule and two to four standard estimators, C0 never differs from 1 by more than 1e-5, and C_eff reduces to the inverse number of distinct estimator families: estimators that agree are merged, and an estimator whose model is wrong is dropped by the weight threshold. C_eff therefore records the composition of the model set, not the quality of the data, and adding a further correct estimator lowers Psi.

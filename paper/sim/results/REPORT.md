## Key findings

1. B.1's Werner values 0.71 and 0.28 are impossible under Eqs. 4 to 6: I(Werner 0.8) = 0.5762 and I(Werner 0.2) = 0.0390 exactly, so Psi <= G_eps x D_hat = 0.5474 and 0.0371. Regenerated: 0.2754 +/- 0.0052 and 0.0197 +/- 0.0023.
2. With n = 2 models (LI-PSD and MLE), C_eff takes only two values in practice. For every full-rank state the two estimators coincide (JSD between them about 1e-17 bits); for the rank-2 separable state they nearly coincide (JSD 9.5e-07 bits). Both are far below delta_i of about 3e-4 to 7e-4, so the models are merged as redundant: n_unique = 1, R = C_eff = 1/2. For the Bell state the cross-validated log-likelihoods differ by tens of nats, so n_active = 1 and C_eff = 1 (the convergence factor did not participate). In every reported mean C0 stays within 1e-5 of 1, so C_eff never varies informatively here (Open Question 7).
3. The epsilon sweep satisfies the 1e-5 bound for every state, but not the 1e-7 bound B.1 claims for the maximally mixed state. The delta_reg sweep up to 1e-4 breaks the 1e-5 bound for every state except Werner p = 0.2 and I/4, because I(rho~) changes linearly in delta_reg with an O(1) coefficient. This is not specific to near-pure states.
4. V2 fails at N = 1e4 per batch: for I/4, R12 = 2.98e-03, which is 3.0e+05 times the floor eps/(1+eps), because the estimated I-hat is about 2.9e-03, not 0. The finite-sample floor scales as N^-1.01.
5. P2: Spearman rho(Psi, p) = 1.0000 for Werner, and equally high for both separable controls. For p < 1 no Psi difference between Werner and its matched separable control is significant. The only significant difference is at p = 1, and it coincides with an n_active change (C_eff 1 versus 1/2), so under Section 8.3 it is a threshold artifact. Psi does not separate the families.
6. P3: the exact asymmetry is linear in the commutator norm (R^2 = 0.9999) but tiny (2.4e-04 at theta = 0.2). At N = 1e4 it sits about 25 times below the noise floor (6.1e-03), so the finite-N fits have R^2 far below 0.9. For a Bell input the exact asymmetry is identically zero.

## C. P2 (Werner family and matched separable controls)

p grid: 21 points, 0 to 1 step 0.05. 30 seeds per point per family (independent seeds per family). Primary rule.

Control families (both separable, both matched to the Werner state at every p):

- `diag`: diag((1+3p)/4, (1-p)/4, (1-p)/4, (1-p)/4) in the computational product basis, i.e. a mixture of the four product states |ij>. Same spectrum as rho_W(p), so purity and entropy match exactly.
- `rotdiag`: the same state rotated by a fixed Haar-random local unitary U_A (x) U_B (seeded), to test dependence on alignment with the SIC.
- Verified: max |dTr rho^2| = 1.1e-15, max |dS| = 4.0e-15 bits (tolerance 1e-4); minimum partial-transpose eigenvalue over both control families = -7.689e-17 (PPT, so separable).

Mixtures of product states are required, and the diagonal construction always succeeds.

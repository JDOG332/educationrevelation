## Implementation choices not fixed by the pre-registration

Made before any phase-4 result was computed, except where marked.

- chi(E) is S(rho_S) (D2); it is also computed independently through the fragment engine with F = E, and the two must agree to 1e-9 (Section 8).
- Fragment sets: exhaustive for N_E <= 10. For N_E = 12, any size with C(12, m) <= 128 is exhaustive; otherwise all contiguous blocks, all complements of contiguous blocks and 128 distinct uniformly random subsets, one fixed set per N_E (seed (MASTER, 0, N_E)). The same set is used for every N_E = 12 state.
- M1(c) hazy: homogeneous, so chi(F) depends only on |F|. It is computed exactly with the GL(2) (Schur-Weyl) block decomposition of p0 X^(x)m + p1 Y^(x)m; each size enters the quantiles with multiplicity C(N_E, m) (equivalent to evaluating every fragment).
- M1 per-state C1/C2 (T2): C1 and C2 are applied per state; the cell aggregation of T3 is not used for M1, whose cells (except (b)) hold one state.
- T1(c) numerical zero: delta_chi(F) <= 1e-13 counts as a violation only if x(F) < 20 (where the local rates predict a deficit above ~1e-9, far above double-precision resolution); delta_chi < -1e-10 always counts.
- D4 / delta_J is computed for contiguous blocks 1..m with m <= min(6, N_E - 1) only.
- T3 overall: a model with fewer than 10 eligible open cells is INCONCLUSIVE and cannot trigger any category; the overall verdict is NO COLLAPSE if an eligible model meets it, else INCONCLUSIVE if any model is INCONCLUSIVE, else the weaker of the two model categories.
- T3b uses fragments from state-eligible states (>= 10 eligible fragments, chi(E) >= 0.5), without requiring cell eligibility; the permutation test uses a seeded subsample of at most 20000 fragments per model.
- T3s: 'homogeneous cells' = M1(a), M2 with homogeneous g_k, and all M4 cells (all M4 sites have the same coupling); M3 is excluded (circuit draws are inhomogeneous). A state needs >= 3 eligible points.
- T5: M1(a) points use N_E = 12; M2 points use homogeneous g_k. All listed M2 and M4 points (including k = 1 and the product M4 point lambda = mu = 0) enter H5, as the rule is written; the k >= 2, open-only count is reported as post-hoc.
- T6: run at N_E = 8 (n = 9 qubits, all 511 observer subsets): M2 all main cells at t in {1, 2, 3}, M4 all main cells, M3 10 draws per cell, M1(a). T6(b) (fidelity bound) on |O| <= 6 for M2 at t = 2, M4, and 3 M3 draws per cell.
- T4: M3 delta_half is the median over the 50 draws; cells are (theta, d). M2 cells are (J, h_S, g, V) with the inhomogeneous g_k drawn separately per N_E (as pre-registered).
- Robustness: M3 is not in the robustness grid, so S-robustness is evaluated on the models present (M2, M4). T3-R uses the M2 N_E = 10 cells only, as written.
- Bootstrap over cells for pass fractions: B = 2000, seed (MASTER, 9, ...).
- Bug found by the unit tests before any run: the trace distance for large observers used non-Hermitian eigenvalues (errors ~1e-8 on exactly-zero differences); replaced by a QR form, exact to round-off.
- Bug fixed after the --quick smoke run: the T6(b) fidelity used scipy sqrtm on rank-deficient marginals (errors up to 1e-5, giving 1175 spurious violations of D <= sqrt(1 - F^2)); replaced by the exact Uhlmann form F = ||Mp^dag Mm||_1. No rule changed.
- Labelling fix after the smoke run: an INCONCLUSIVE T3 verdict that is also INCONCLUSIVE on the robustness grid is not called ROBUST (there is no verdict to be robust). No rule changed.
- Seen in the smoke run, not changed: the pre-registered T2(d) expectation (unequal priors fail C1) is wrong. For pure branches the asymptotic deficit is p q log2(p/q) |gamma|^2 / ((p - q) H(p)), against |gamma|^2 / (2 ln 2) for p = 1/2: a ratio of 1.025 at p0 = 0.8 and 1.086 at p0 = 0.95, inside ln 1.25. p0 = 0.95 is ineligible anyway (chi(E) <= H(0.95) = 0.29 < 0.5). The T2 verdict is applied as written.
